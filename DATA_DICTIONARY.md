# RetailStream Data Dictionary

| Column | Description |
|---|---|
| event_id | Unique identifier for each sales event |
| event_timestamp | Time when the sales event was generated |
| order_id | Identifier for the retail order |
| customer_id | Synthetic customer identifier |
| store_id | Identifier for the store |
| region | Store region, such as Midwest or West |
| product_id | Identifier for the product |
| category | Product category |
| quantity | Number of units purchased |
| unit_price | Price of one product unit |
| total_amount | Total order value: quantity × unit price |
